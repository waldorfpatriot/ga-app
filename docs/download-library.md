# Complete download library

The Apple reader includes the complete catalog from the existing Kutscherei
collection plus four recovered working editions: 463 entries, 324 readable texts,
and 139 unavailable entries. The deployed reader release also serves all
324 readable texts. The
five previously normalized books keep their scope and section IDs; documented
proofreading repairs can update their text and checksums. Only full
volumes are offered. GA 120 downloads as a complete eleven-lecture edition;
the former excerpt has been removed. Other books download as needed; app-private
notes and reading positions remain in the existing local/CloudKit store.

## Sources and scope

The source is the prepared library at
`/Volumes/iMac/programmier-projekte/ga/library` on Kutscherei. Its 320 EPUBs have
existing source assessments, navigation, semantic notes and structural audits.
The original EPUB collection remains unchanged. The prepared collection had 143 absent entries. Four have since been recovered
from their original German FVN EPUB sources; the other 139 remain catalog
entries. Downloaded research candidates do not become reader books automatically.
See [source-recovery.md](source-recovery.md) for recovery provenance and rebuilds.

`tools/import_library.py` reads the EPUB spine, keeps source spelling and chapter
continuations, and excludes generated title/navigation pages and note indexes.
`tools/library-scope.json` records the source-supported start for every available
volume and 674 identified section exclusions. Unheaded author prefaces and
explicit third-party transitions have separate text markers. Tagged editorial
notes are excluded; source-defined author annotations and actual page labels are
retained. Historical pages are absent when the source supplies no valid anchors.
Source EPUB hashes, original text for the developer diff, scope decisions and
warnings remain in the compressed server payloads. Scope anchors are bound to
their source EPUB hashes; changed sources require reviewing those anchors before
reimporting.

The existing source collection is trusted for volume completeness. The 315 added
texts retain their working-edition provenance and source quality notes. The five
earlier normalized books retain their previous status.

## Rebuild

After source import/finalization, apply the
[readability and proofreading pass](proofreading/README.md) before export.
Its per-GA ledger records the text repairs while retaining source originals.

Use Python with `lxml`, for example the configured Codex dependency Python. Build
into a fresh staging directory before copying into `server/priv`:

```sh
python3 tools/import_library.py /path/to/prepared/library /tmp/ga-import \
  --existing-content server/priv/content --scope tools/library-scope.json
python3 tools/finalize_library.py /tmp/ga-import
rsync -a /tmp/ga-import/content/ server/priv/content/
rsync -a /tmp/ga-import/library/ server/priv/library/
```

New payloads use deterministic `.json.gz` storage; the five curated books retain
plain JSON. GA 120 has only its complete compressed edition; the old seed file
has been removed. `finalize_library.py` aligns page-marker handling, source metadata and
section checksums with the native server's normalization and verifies every
catalog/download identity.

The standalone import regressions require `lxml`:

```sh
python3 tools/test_import_library.py
python3 tools/test_finalize_library.py
python3 tools/check_download_library.py
cd server
GA_SKIP_REPO=true mix test
```

The complete metadata catalog lives inside the release at
`server/priv/library/catalog.json`. Runtime catalog coverage does not depend on
the working directory or an external research folder. Catalog requests read
metadata rather than hundreds of text bodies. Text and manifests validate their
payloads on demand; missing, corrupt or partial content returns 404. Available
catalog entries and public content declare `content_completeness: complete`.
Native downloads expose
ETags and manifests with SHA-256 and exact byte counts.

## Production delivery

The reader uses `https://fototausch.eu/ga-reader` on iPhone, iPad and Mac. The
existing EPUB service remains at `https://fototausch.eu/api/ga/books`. This app's
reader JSON uses a separate static snapshot generated by the same native
`GA.Catalog` functions as the Phoenix API. Static catalog filtering happens
locally in the app; the Phoenix development API also accepts query filters.

Current reader release: `20261009T085828Z-53e4426372bb`, with 463 entries and
324 complete downloads. All 1,252 uploaded files passed remote hash checks.
The previous release, `20261008T153608Z-7cf95c1c9ab7`, remains available for rollback.

Generate a fresh public snapshot and the matching lightweight Apple resource:

```sh
cd server
MIX_ENV=test GA_SKIP_REPO=true mix run ../tools/export_server_library.exs \
  /tmp/ga-reader-delivery ../apple/GA/BundledCatalog/catalog.json
cd ..
python3 tools/publish_reader_library.py /tmp/ga-reader-delivery
```

For initial route installation, append `--configure-nginx`. That installs only
`/ga-reader/`, backs up the existing Fototausch configuration, checks `nginx -t`,
and reloads Nginx. It does not require a new application service or database.
The publisher rejects source diffs in the public tree, validates manifest hashes,
uploads into a new immutable release, verifies every remote size/hash, then
atomically changes `/var/lib/ga-reader/current`. Its output records the preceding
release. Keep prior snapshots for rollback by atomically switching that symlink
back; no service restart is required for a library-only update.

Production exposes the native reader paths, including:

- `/ga-reader/api/catalog`
- `/ga-reader/api/catalog/ga-001`
- `/ga-reader/api/catalog/ga-001/content`
- `/ga-reader/api/catalog/ga-001/manifest`

It does not publish developer proofing payloads. `GA_FRONTEND=developer` uses
the local Phoenix server; `GA_SERVER_BASE_URL` overrides the base URL and
preserves any service-path prefix. Five complete books (77 sections) are bundled;
the remainder is delivered per full volume and saved atomically on the device.
The app verifies each download against its advertised section count. Old excerpt
caches are ignored while private notes and reading positions remain intact.

The reader checks for book updates at launch, when returning to the app, and
through **Nach Updates suchen** in the library menu. Saved books with a newer
server edition show **Update verfügbar** in the library and **Buch aktualisieren**
in their actions and details. **Updates verfügbar** filters the library to those
books. Updating is an explicit action; the saved edition stays readable offline
until its replacement has downloaded and passed its full-book and checksum checks.
Failed updates leave the saved text intact. Personal notes, bookmarks and reading
state remain in their separate store.

Public catalogs and manifests advertise `content_revision`, the SHA-256 of the
exact reader download, and `content_updated_at`. Text, contents and reading-layout
changes therefore all produce a new edition. The cache records the installed
revision and complete section count, including when a newer edition adds sections.
Legacy saved books remain readable and can acquire a revision through an update.
A dated packaged catalog cannot be replaced by an older service snapshot.

Before installing a rebuilt app, verify its actual bundled resources against the
current proofreading ledger and the public snapshot:

```sh
python3 tools/check_apple_build_content.py "/path/to/GA iOS.app" \
  --snapshot /tmp/ga-reader-delivery
python3 tools/check_book_updates.py --simulator-id <your-QA-simulator-UUID>
```

The update regression uses a disposable local service and restores its two test
cache files. It checks a failed update, successful replacement and reading the
updated book after an offline relaunch.

After publication, `python3 tools/check_live_library.py` checks all 324 live
download HEADs and manifests after publishing the recovery release, full JSON/checksum samples, missing/private-resource
404s and conditional catalog requests. The focused native UI regression downloads
GA 001, then relaunches against an unreachable server and reopens its saved text.
